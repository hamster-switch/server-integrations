# new-api 补丁功能与页面升级

## Goal

在现有 new-api Hamster Switch YAML 补丁基础上，补齐面向用户的“配置订阅”、“配置订阅教程”、YAML 生成/维护、导入 Hamster Switch 和生命周期操作。

## Confirmed Facts

- 上游 new-api 的 Token 列表、搜索和单项接口会在服务端复制对象并用 `GetMaskedKey` 替换 `key` 后返回；完整 Token 不随默认列表进入浏览器。
- 用户点击显示、复制或批量复制时，前端调用 `POST /api/token/:id/key` 或 `POST /api/token/batch/keys` 获取明文；端点使用用户会话、所有权校验、关键操作限流和禁用缓存，但未发现二次认证要求。
- Token 仍以可恢复明文存储在数据库；显式取明文只是缩小默认暴露面，不代表服务端不可恢复或不可泄露。
- Token 明文获取路由只经过 `UserAuth`，而现有通用操作审计仅对 `AdminAuth/RootAuth` 的写方法兜底，因此显示/复制 Token 没有专门审计事件。
- 常规访问日志只记录状态、耗时、IP、方法和路径，不记录请求/响应体；用量日志记录 Token ID 和名称。中继错误会走敏感信息掩码，但该掩码重点覆盖 URL、IP、域名等，不能作为任意 API Key 文本的完整兜底保证。
- 公共 `/api/status` 返回站点公开配置；管理员 `/api/status/test` 会检查数据库并返回 HTTP 统计。两者均不需要也不返回 Token 明文。

- 现有用户入口位于 API Keys 页面，通过 `Hamster Switch URL` 弹窗创建订阅 URL；管理员侧目前只有 YAML 诊断/设置入口标记。
- 补丁已有 options、preview、create、download 端点以及专用 Token 生成逻辑。
- 订阅 URL 与专用 Token 生命周期绑定；上游渠道密钥不得导出。
- 新的生产安装/检查/更新路径只面向 Linux 服务器。
- 当前功能仍处于开发阶段，没有需要保护的正式用户或已部署 Hamster 刷新链路，因此允许对旧订阅 URL 做破坏性迁移。

## Requirements

- 新增的“配置订阅”页面在凭据展示上对齐 sub2api，而不是复用 new-api 原 Token 列表的服务端脱敏方式：订阅接口可向已登录且通过所有权校验的页面返回完整专用 Token 和完整 YAML，前端默认做首 6 位、末 4 位的视觉脱敏。
- 复制 Token、复制订阅 URL、复制 YAML 和下载 YAML 直接使用页面已取得的完整值，不新增显式揭示端点、二次认证、查看限流或专门的查看/复制审计事件。
- 该决定只适用于 Hamster 订阅功能；new-api 原有 API Keys/Token 页面继续保持服务端脱敏和按需取明文的现状，不在本轮重构。
- 最终订阅 YAML 保留完整专用客户端 Token；不得把上游渠道密钥加入模板上下文、管理接口或 YAML。
- 服务访问日志、错误记录和健康检查沿用 new-api 既有实现，本轮不建立跨项目统一安全日志契约，也不额外把完整订阅凭据写入新日志字段。
- 建立与 sub2api 对齐的独立“配置订阅”页面，不再把完整生命周期塞入 API Keys 弹窗；侧边栏、路由标题、页面标题、空状态和相关操作文案使用同一名称。
- `web/default` 与 `web/classic` 两套前端必须提供功能等价的“配置订阅”能力；可按各自组件体系实现，不要求像素一致。
- 立即移除 API Keys 页面既有 `Hamster Switch URL` 入口，不保留跳转、兼容入口或迁移期，也不继续维护旧弹窗创建流程。
- default 删除 `api-keys-primary-buttons.tsx` 中的旧按钮、`api-keys-dialogs.tsx` 中的旧弹窗挂载及不再被新页面复用的触发状态；classic 不新增对应 API Keys 兼容入口。可复用的 API 类型与请求函数迁移到“配置订阅”模块，废弃且无引用的旧弹窗组件删除。
- 移除旧前端入口不等于删除订阅后端能力；现有 options/preview/create/download 契约由新的“配置订阅”页面复用、调整或扩展。
- 教程入口和二级页统一命名为“配置订阅教程”，提供步骤化教程、通用内容、管理员定制内容及图片支持。
- 教程采用稳定步骤 ID 的通用底稿与站点覆盖层；管理员可编辑文案、替换图片、隐藏/排序通用步骤并新增站点步骤。
- 教程图片支持通用 Release 资产、本站上传和管理员外链三种来源。
- 外链由服务器执行 SSRF 防护与图片校验后代理缓存，浏览器不直接访问第三方源站。
- YAML 由服务器 Token、外部项目端点、模型与展示元数据生成，并保持 Hamster Switch 契约兼容。
- 补齐导入 Hamster Switch、禁用、编辑、删除操作及后端端点。
- 禁用是可恢复操作：在同一事务中把订阅标记为禁用并停用其全部专用 Token，但不重新生成、不删除凭据，也不改变订阅 URL；禁用期间原 URL 返回 `410 Gone` 和明确的已禁用错误。
- 重新启用时在同一事务中恢复订阅及原专用 Token，原 URL 和原 YAML 中的凭据继续有效，用户无需重新导入 Hamster Switch。
- 删除是用户侧不可恢复操作。确认后事务化删除订阅并撤销/删除其全部专用 Token；原订阅 URL 永久失效并返回 `404`，再次创建必须生成新 URL 和新 Token。数据库内部可使用软删除维持关联完整性，但不提供回收站或恢复入口。
- 删除弹窗中文正文固定为 `确定要删除'{name}'吗？此操作无法撤销。`，其中 `{name}` 使用订阅名称；两套前端保持行为等价，但分别复用原项目组件：default 使用现有 `AlertDialog` 与 destructive 按钮、提交态和 toast/刷新流程，classic 使用 Semi `Modal.confirm`/`Modal` 的 warning/danger 交互和原有提示/刷新流程。
- 删除请求失败时保留当前数据并展示各前端原有风格的错误提示；成功后关闭弹窗、提示成功并刷新列表，不做前端假删除。
- “导入 Hamster Switch”仅发起深链并预填桌面端“从 URL 导入”页面，不把网页点击视为已导入成功。
- 新增持久化订阅实体和稳定 URL；普通编辑不改变 URL，刷新原 URL 返回当前已发布配置。
- 升级后不兼容旧版 API Keys 弹窗签发的无状态 `hs_<payload>.<signature>` URL：删除旧签发入口并停止接受旧 Token 格式，新下载端点只解析持久化“配置订阅”实体签发的新 URL；旧 URL 直接失效。
- 不尝试按 `${name} - ${group}` 名称自动识别或批量删除旧专用 Token，因为该命名与普通用户 Token 不可可靠区分；开发环境如需清理，由开发者手动删除确认过的 Token 或重置开发数据库。
- 分组增删与对应专用 Token 的创建/撤销必须事务化；禁用与删除分别具有独立语义。
- 管理员维护范围不得允许导出渠道密钥或破坏必需字段。
- 管理员可直接编辑完整原始 YAML 模板；模板通过受限变量注入运行时订阅数据，不得执行任意代码。
- 受限 DSL 仅开放登记变量、providers/models 循环和简单条件，不得读取环境变量、文件、网络或调用函数。
- 模板只开放规范化安全上下文；可使用该订阅专用客户端 Token，但不得访问上游渠道密钥或任意数据库/环境字段。
- 模板硬错误不可绕过；允许保存无效草稿，但禁止发布并替换当前有效版本。
- 非关键警告允许管理员在查看详情后确认发布，并记录确认人、时间和警告集合。
- 通用教程/YAML 更新必须经管理员确认，并在站点存在定制内容时避免原地覆盖。

## Dependencies

- 依赖“远程补丁与内容发布机制”定义通用内容版本和覆盖契约。
- 依赖“Hamster Switch 订阅深链导入契约”定义导入按钮行为。

## Acceptance Criteria

- [ ] 用户能独立查看和管理自己创建的 Hamster Switch 订阅。
- [ ] 独立页面具备列表、创建/预览、复制 URL、导入 Hamster、教程、禁用、编辑、删除与 YAML 预览能力。
- [ ] default/classic 共用后端契约与验收用例，不得出现一套可管理、另一套只有入口或只读的差异。
- [ ] YAML 不泄露上游渠道密钥，专用 Token 的禁用/删除会使订阅 URL 失效。
- [ ] 完整模板有草稿、预览、校验、发布版本和回滚流程；无效模板不能替换当前有效版本。
- [ ] 页面、教程和 YAML 行为与 sub2api 共享契约，同时允许按上游产品结构实现不同 UI。
- [ ] 同一步骤发生远程与站点修改冲突时逐项提示管理员处理，不自动合并。
- [ ] default/classic 的 API Keys 页面均不存在 `Hamster Switch URL` 旧入口或旧弹窗；“配置订阅”是唯一用户入口，订阅后端能力仍可从新页面完整使用。
- [ ] 编辑成功后原 URL 返回完整新版本；编辑失败时原 URL 继续返回完整旧版本。
- [ ] 教程/YAML 更新提供版本与差异预览，管理员拒绝更新时维持当前站点内容。
- [ ] Hamster 订阅管理页面默认视觉脱敏，复制或下载所得内容包含可用的完整专用 Token，且不包含上游渠道密钥。
- [ ] 禁用后原 URL 返回 `410 Gone` 且专用 Token 不可调用；重新启用后原 URL、原 Token 和 Hamster 刷新订阅能力全部恢复。
- [ ] default/classic 删除弹窗均显示准确订阅名称和不可撤销文案；删除成功后原 URL 返回 `404`、全部专用 Token 不可调用且页面不存在恢复入口。
- [ ] 两套前端的页面业务名称均为“配置订阅”，教程入口和二级页标题均为“配置订阅教程”，且不会覆盖或改名 new-api 原有的付费套餐“订阅管理/我的订阅”。
- [ ] 旧版 `hs_<payload>.<signature>` URL 在升级后不可下载配置；新页面仅展示和管理持久化实体签发的新 URL，迁移过程不会按模糊名称误删普通 Token。
