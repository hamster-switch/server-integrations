# sub2api 配置订阅权限、编辑与内容管理改进

## Goal

将 sub2api 的配置订阅功能调整为面向普通用户的安全订阅使用流程，并完善管理员对订阅凭据可见性、订阅模板和教程内容的管理能力；同时把 sub2api 与 new-api 补丁的历史开发文档迁移到补丁所属项目，而不再由 Hamster Switch 主项目承载。

## Background and confirmed facts

- 当前两个补丁的历史 PRD、设计和实施记录位于 Hamster Switch 的 `.trellis/tasks/archive/2026-07/07-19-*-patch-upgrade/`。
- `sub2api-hamster-switch-yaml-patch` 与 `new-api-hamster-switch-yaml-patch` 是本地补丁包目录，但不是 Git 仓库；正式发布代码由 `hamster-switch/server-integrations` Git 仓库维护，并已按 `releases/sub2api/`、`releases/new-api/` 分目录。
- 当前普通用户路由暴露 `GET /api/v1/keys/hamster-switch/subscriptions/:id/yaml`，列表页也直接提供“查看 YAML”按钮；管理员管理路由已经由 `AdminOnly` 保护。
- 当前创建和编辑共用一个表单，但自定义密钥区域带有 `!editingSubscriptionId` 条件，编辑时不可见；后端更新既不会替换已有分组密钥，也会把已有自定义密钥误判为重复值。
- sub2api 原生 API 密钥编辑同样不允许修改密钥字符串：自定义密钥只在创建时出现；编辑只更新名称、分组、状态、IP、额度、限速和有效期。因此配置订阅编辑应沿用该既有安全策略。
- 当前配置订阅专用密钥直接写入 `api_keys` 表，因此会进入普通 API 密钥列表；尚无“订阅专用密钥隐藏”持久化设置。
- 当前模板仅开放一段原始 YAML 文本，默认变量集合不包含订阅或 provider 的 `description`、`icon`、`home_url`、`website_url`、`category`、`notes`、`pricing`、`features`、`icon_color`、`sort_index` 等 Hamster Switch 已支持字段。
- sub2api 已有 `site_logo` 设置及 `ImageUpload` 上传组件，可以作为默认订阅图标来源，无需新建另一套站点 Logo 存储。
- 当前 sub2api 分组实体没有持久化 Logo/icon 字段，分组页面图标由平台类型生成；本任务明确复用该平台映射，不新增分组 Logo 字段。
- 教程管理前端将后端返回的 `base`、`overrides` 直接视为非空；当任一字段为 `null` 时，对 `.steps`、`.find` 或 `.some` 的调用会触发运行时错误。

## Requirements

### R1. 普通用户只使用订阅，不查看原始 YAML

- 普通用户列表操作中的“查看 YAML”改为“使用订阅”。
- 点击“使用订阅”后展示当前“配置订阅教程”内容，告诉用户如何复制并使用订阅 URL；该页面和登录态管理 API 不得向普通用户显示、复制或下载原始 YAML。
- 原始 YAML 预览、复制和下载能力仅管理员可用，后端权限必须同步收紧，不能只隐藏前端按钮。
- 普通用户仍可复制自己的稳定订阅 URL，Hamster Switch 仍可通过带 `hsc_` 下载令牌的公共 URL 获取 YAML。这里的权限边界只约束页面和登录态管理接口；任何持有订阅 URL 的调用方在技术上仍可下载 YAML，产品文案不得承诺“订阅持有人绝对无法取得 YAML”。

### R2. 完整可用的配置订阅编辑

- 编辑入口打开与创建配置订阅一致的名称、分组与高级设置，并按 sub2api 原生 API 密钥编辑策略处理密钥值。
- 已有分组的专用密钥保持不变，不显示、不回填也不允许直接替换；本任务不新增“修改密钥字符串”或“重新生成密钥”能力。
- 编辑时新加入的分组显示创建式自定义密钥输入：留空自动生成，填写时按原生自定义密钥规则校验；移除分组时事务化撤销对应专用密钥。
- 编辑时正确回填名称、分组、IP 白名单/黑名单、额度、限速和有效期；关闭某项高级设置必须显式清除对应后端值。
- 更新成功后保持订阅 URL 稳定；被移除分组的密钥必须立即失效，不能留下游离可用凭据。
- 编辑失败时事务整体回滚，页面保留用户输入并展示可理解的错误。

### R3. 管理员控制订阅专用密钥是否显示在 API 密钥页

- 仅管理员在配置订阅页顶部、配置订阅教程入口左侧看到“隐藏 API 密钥显示”选择控件。
- 开启后，由配置订阅为不同分组生成或绑定的专用 API 密钥不再出现在普通用户 API 密钥列表与搜索结果；关闭后恢复显示。
- 管理员查看用户详情或执行审计、排障时仍可看到这些密钥；管理员接口不应用普通用户列表隐藏过滤。
- 隐藏只影响 API 密钥管理页面及其列表接口，不得影响订阅下载、鉴权、额度、限速、禁用、启用或删除行为。
- 设置需要持久化并在多节点部署下保持一致；普通用户不能读取管理细节或修改该设置。
- 升级后的默认值为关闭，保持现有 API 密钥列表行为；只有管理员主动开启后才隐藏。

### R4. “订阅模板管理”与半开放模板配置

- “YAML 模板管理”统一改名为“订阅模板管理”。
- 管理界面默认读取 sub2api 站点配置与所有可订阅分组，生成一份完整、可编辑的默认模板示例。
- 订阅级默认值优先复用站点名称、站点 Logo、站点说明和站点地址；管理员可覆盖订阅 `description`、`icon`、`home_url` 等字段。
- provider 级 `name` 默认读取分组名称，`icon` 默认由分组 `platform` 映射为 Hamster Switch 支持的图标名，`description` 默认留空；管理员可以针对每个分组显式覆盖这些字段，显式清空时不重新套用默认值。
- provider 级默认值按全部分组生成，并允许管理员覆盖 Hamster Switch 支持且安全的其他展示字段；每个用户或每次渲染都不同的值继续以受限 `{{...}}` 变量表达，例如 API 密钥。
- 新增分组自动进入模板管理并生成默认 provider 配置；分组重命名或平台变化时，未覆盖的 `name`/`icon` 跟随默认值变化，已覆盖值保持不变。
- 删除分组时同步删除该分组的订阅模板覆盖配置，不保留孤立覆盖记录。
- 模板为“半开放式”：允许编辑明确支持的字段和安全变量，不允许执行任意代码、读取服务器环境变量、导出上游账号凭据或破坏 Hamster Switch 必需结构。
- 模板管理采用“结构化展示字段 + 高级原始 YAML 布局”的混合编辑方式：基础区域维护订阅级和分组级安全展示字段，高级区域维护字段顺序、可选字段和受限变量。
- 管理界面提供基于当前全部分组的完整 YAML 实时预览；用户专属 API 密钥等动态值在管理预览中保持 `{{...}}` 占位符，不显示任何真实用户密钥。
- 发布时结构化配置与高级布局作为同一版本共同校验、发布和回滚，避免只回滚布局而保留不匹配的展示字段覆盖。
- 保存草稿、诊断、警告确认、发布、版本历史和回滚能力继续保留。

### R5. 修复教程管理空值崩溃

- 修复 `Cannot read properties of null (reading 'find')`。
- 前后端都应将无基础教程、无覆盖项、无候选版本视为合法空状态，并返回或规范化为空对象/空数组。
- 空状态下管理员可以新建站点步骤，检查更新、保存覆盖、删除覆盖等操作不得因空值崩溃。
- 增加覆盖 `base=null`、`overrides=null`、`candidate=null` 及空数组的前后端测试。

### R6. 补丁开发文档归位

- 将 sub2api 和 new-api 补丁既有开发文档分别迁移到正式维护仓库 `server-integrations` 下的 `docs/projects/sub2api/` 与 `docs/projects/new-api/`。
- 迁移后 Hamster Switch 主项目不再保存这两套补丁的重复开发文档，只保留必要的跨项目契约或链接。
- 新的 sub2api PRD、设计与实施规划也应落在 `server-integrations/docs/projects/sub2api/`。
- 文档迁移必须保留历史决策、验收证据、Release/提交引用及父任务关系说明。

## Acceptance Criteria

- [ ] 非管理员无法通过页面或已登录用户 API 获取原始 YAML，但订阅 URL 下载流程仍正常。
- [ ] “使用订阅”展示与“配置订阅教程”相同的已发布内容和图片，并提供订阅 URL 使用指引。
- [ ] 编辑表单完整回填并能修改名称、分组及全部高级设置；已有分组密钥不可改，新分组可自定义或自动生成密钥，更新保持 URL 不变且移除分组的密钥立即失效。
- [ ] 管理员隐藏开关持久化生效，开启时订阅专用密钥从普通用户 API 密钥页及搜索响应消失、管理员审计视图仍可见，关闭后恢复；订阅本身持续可用。
- [ ] 管理入口和文案统一为“订阅模板管理”，默认模板包含站点与所有分组的可配置展示字段以及动态值变量。
- [ ] 自定义 icon、description 等受支持字段能通过模板发布并被 Hamster Switch 正确解析、导入和展示。
- [ ] 教程管理对空基础内容、空覆盖和空候选均不崩溃，并有回归测试。
- [ ] 两个补丁的历史开发文档及新 sub2api 规划位于确认后的项目目录，Hamster Switch 主项目中不存在重复副本。
- [ ] 后端 Go 测试、前端类型检查与构建、Hamster Switch 订阅契约测试全部通过。

## Out of scope

- 不改变 Hamster Switch 订阅协议之外的普通 API 密钥鉴权语义。
- 不允许模板访问 sub2api 上游账号密钥、OAuth 凭据或任意服务器文件/环境变量。
- 本规划阶段不修改业务代码，也不发布新的补丁 Release。
